# Swing System (Kurzfassung)

Entscheidungshilfe, die täglich rund 1.050 US- und deutsche Aktien analysiert: Geschäftsmodell-Typ erkennen, passend bewerten (DCF, ROTCE, NAV, SOTP, eingepreiste Rendite), Swing-Setups mit statistisch belegten Stops und Tranchenpläne fürs Investment. Backtest ohne Zukunftswissen (Test 2012–19, Validierung 2020–21). Daten sind aus Lizenzgründen nicht enthalten. Details siehe [README.md](README.md).
